# Security Policy / Política de Segurança

## English

### Reporting a vulnerability
Use GitHub private vulnerability reporting: <https://github.com/sayymon/software-engineer-kit/security/advisories/new\>. Please do not open a public issue for a vulnerability. Include the affected file or page, steps to reproduce and the impact you see. The owner acknowledges reports and works on a fix with you before any public disclosure.

### Supported versions
Only the latest release (the newest `vX.Y.Z` tag) receives fixes.

### Scope
The static site, the build and validation tooling, and the GitHub workflows of this repository.

## Português

### Como reportar uma vulnerabilidade
Use o relato privado de vulnerabilidades do GitHub: <https://github.com/sayymon/software-engineer-kit/security/advisories/new\>. Evite abrir issue pública para uma vulnerabilidade. Informe o arquivo ou a página afetada, os passos para reproduzir e o impacto que você enxerga. O responsável confirma o recebimento e trabalha com você na correção antes de qualquer divulgação pública.

### Versões suportadas
Somente a última release (a tag `vX.Y.Z` mais recente) recebe correções.

### Escopo
O site estático, as ferramentas de build e validação, e os workflows do GitHub deste repositório.
