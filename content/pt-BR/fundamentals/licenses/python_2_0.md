# Python License 2.0 (PSF License Version 2)
## Em resumo
A PSF License Version 2 é a licença permissiva do interpretador Python: duas condições simples (reter o copyright do PSF e resumir as mudanças em derivados), sem garantia e sem concessão de patentes. O texto completo, incluindo os acordos históricos BeOpen/CNRI/CWI das versões antigas, foi lido na lista SPDX em 2026-11-27.

## Como aplicar
Copie o texto oficial para `LICENSE` do derivado de Python, mantenha o aviso de copyright do PSF e acrescente um resumo das suas mudanças.
