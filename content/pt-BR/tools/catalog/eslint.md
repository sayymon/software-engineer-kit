## 📝 Descrição
Linter plugável para JavaScript e JSX que analisa o código estaticamente para encontrar problemas, corrige muitos deles automaticamente e roda integrado a editores e pipelines de CI.
## ⏰ Quando Utilizar
- Lint de JavaScript e TypeScript com regras configuráveis, parsers customizados e plugins próprios.
- Impor qualidade em pipelines de CI: o site oficial declara ser o linter de JavaScript com mais downloads no npm (mais de 203 milhões de downloads por semana, lido em 2026-11-27).
- Correção automática syntax-aware (eslint --fix) em bases de código grandes.
### Quando NÃO utilizar
- Python: use [[ruff|ruff]].
- Quando lint, formatação e organização de imports precisam vir de uma única ferramenta JS/TS: veja [[biome|Biome]].
- Quando a necessidade é só formatação de código: [[prettier|Prettier]] cobre sem sobrepor regras de lint.
