## 📝 Descrição
Cliente HTTP Python com APIs síncrona e assíncrona e suporte a HTTP/2.
## ⏰ Quando Utilizar
- Opção da faixa melhor custo-benefício em [[clientes_http_api|Clientes HTTP e API]].
- Cliente HTTP síncrono e assíncrono para Python, com API amplamente compatível com Requests e suporte a HTTP/1.1 e HTTP/2.
- Escolha para o melhor equilíbrio entre custo, capacidade e esforço de adoção.
### Quando NÃO utilizar
- Quando o orçamento precisa ser zero ou o requisito é o máximo de recursos corporativos.
