## 📝 Descrição
Servidor MCP universal para Postgres, MySQL, SQL Server e SQLite.
## ⏰ Quando Utilizar
- Referência da faixa mais barata em [[mcp_banco_dados|MCP de banco de dados]].
- Escolha quando o custo precisa ficar o mais baixo possível (gratuito ou código aberto).
### Quando NÃO utilizar
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
