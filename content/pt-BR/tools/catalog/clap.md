## 📝 Descrição
Biblioteca Rust de parsing de argumentos de linha de comando com subcomandos, validação e ajuda automática, em APIs builder e derive.
## ⏰ Quando Utilizar
- Referência da faixa de melhor custo-benefício em [[bibliotecas_cli|Bibliotecas de CLI]] para Rust; filtre pela linguagem do projeto no kit.
- Escolha quando a linguagem e o ecossistema do projeto combinam com a ferramenta.
- Duas APIs para o mesmo parser: builder procedural e derive declarativo, com validação, ajuda e erros de uso gerados automaticamente nas duas.
### Quando NÃO utilizar
- Quando o CLI é trivial demais para uma dependência de parsing: std::env::args resolve sem biblioteca.
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
