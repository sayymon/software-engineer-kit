## 📝 Descrição
Biblioteca JavaScript para criar e exibir gráficos 3D animados no navegador com WebGL.
## 🔎 O que oferece
O README do repositório (lido em 2026-11-24) descreve uma biblioteca 3D leve, multi-navegador e de uso geral. As versões atuais incluem renderizadores WebGL e WebGPU, e há renderizadores SVG e CSS3D como complementos. O repositório oferece exemplos, documentação e manual.
## ⏰ Quando Utilizar
- Criar cenas 3D e experiências imersivas no navegador.
- Base para bibliotecas de visualização, como 3d-force-graph.
### Quando NÃO utilizar
- Páginas simples em que CSS e imagens resolvem, pois a biblioteca adiciona peso e complexidade.
