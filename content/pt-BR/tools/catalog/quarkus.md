## 📝 Descrição
Framework Java nativo de nuvem com inicialização rápida e baixo consumo de memória, modo dev com recarga viva e compilação nativa opcional.
## ⏰ Quando Utilizar
- Microsserviços e funções serverless em Java com tempo de partida curto.
- Equipes Java que querem Jakarta EE e MicroProfile com experiência de desenvolvimento moderna.
### Quando NÃO utilizar
- Quando o time já domina [[spring_boot|Spring Boot]] e a migração não paga o custo.
- Aplicações fora da JVM.
