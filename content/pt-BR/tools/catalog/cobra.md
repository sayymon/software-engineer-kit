## 📝 Descrição
Biblioteca Go para CLIs com subcomandos aninhados, flags POSIX e geração automática de ajuda, autocompletar de shell e páginas man.
## ⏰ Quando Utilizar
- Referência da faixa mais barata em [[bibliotecas_cli|Bibliotecas de CLI]] para Go; filtre pela linguagem do projeto no kit.
- Escolha quando a linguagem e o ecossistema do projeto combinam com a ferramenta.
- Padrão do ecossistema: projetos Go como Kubernetes, Hugo e GitHub CLI usam Cobra, e o gerador cobra-cli cria o esqueleto do comando.
### Quando NÃO utilizar
- Quando o CLI é trivial demais para subcomandos: o pacote flag da biblioteca padrão de Go resolve sem dependência.
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
