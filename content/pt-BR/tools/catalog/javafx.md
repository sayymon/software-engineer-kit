## 📝 Descrição
Toolkit de interface rica para JavaSE dentro do projeto OpenJFX do OpenJDK, com FXML para layout, Scene Builder para design visual e distribuição via Maven Central.
## ⏰ Quando Utilizar
- Outra opção na faixa de melhor custo-benefício em [[frameworks_desktop|Frameworks de desktop]] para Java; filtre pela linguagem do projeto no kit.
- Escolha quando a linguagem e o ecossistema do projeto combinam com a ferramenta.
- Ferramenta de UI madura da JVM: roda em desktop e estende a mobile e embarcados com a cadeia Gluon.
### Quando NÃO utilizar
- Quando a política de licenças recusa GPL-2.0 com Classpath Exception: avalie [[electron|Electron]], [[tauri|Tauri]] ou [[qt|Qt]].
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
