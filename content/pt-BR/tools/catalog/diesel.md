## 📝 Descrição
ORM e query builder completo para Rust.
## ⏰ Quando Utilizar
- Outra opção em [[orm_acesso_dados|ORM e acesso a dados]]; filtre pela linguagem do projeto no kit.
- ORM completo Rust: escolha quando o projeto quer mapeamento objeto-relacional com abstrações de custo zero e consultas verificadas em compile-time.
### Quando NÃO utilizar
- Quando o orçamento precisa ser zero ou o requisito é o máximo de recursos corporativos.
