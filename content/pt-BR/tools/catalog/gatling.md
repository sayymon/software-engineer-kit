## 📝 Descrição
Ferramenta de teste de carga com cenários como código em Java, Kotlin, Scala, JavaScript ou TypeScript e relatórios HTML detalhados.
## ⏰ Quando Utilizar
- Cenários de carga versionados e revisados como código.
- Equipes JVM ou JavaScript que querem relatórios prontos por execução.
### Quando NÃO utilizar
- Quando a equipe prefere interface gráfica e plugins amplos: [[apache_jmeter|Apache JMeter]] atende.
