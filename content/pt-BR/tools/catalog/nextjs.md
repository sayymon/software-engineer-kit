## 📝 Descrição
Framework full-stack sobre React com roteamento, renderização no servidor, cache e data fetching, e ferramentas de build em Rust.
## ⏰ Quando Utilizar
- Outra opção na faixa de melhor custo-benefício em [[frameworks_frontend_web|Frameworks de frontend web]]; filtre pela linguagem do projeto no kit.
- Escolha quando a linguagem e o ecossistema do projeto combinam com a ferramenta.
- Full-stack sobre React: roteamento por arquivo, renderização no servidor e cache no mesmo framework.
### Quando NÃO utilizar
- Quando o site é puramente estático ou um SPA sem servidor: Astro, [[svelte|Svelte]] ou Vite direto resolvem com menos camadas.
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
