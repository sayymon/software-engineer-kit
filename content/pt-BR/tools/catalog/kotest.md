## 📝 Descrição
Framework de testes para Kotlin com propriedades e matchers.
## ⏰ Quando Utilizar
- Outra opção na faixa qualidade máxima em [[frameworks_testes|Frameworks de testes]]; referência de testes para Kotlin na matriz do kit.
- Escolha quando a linguagem e o ecossistema do projeto combinam com a ferramenta.
### Quando NÃO utilizar
- Quando o projeto é Java puro, sem dependências Kotlin: [[junit5|JUnit 5]] é a referência da faixa.
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
