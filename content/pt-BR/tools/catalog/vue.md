## 📝 Descrição
Framework progressivo de interfaces com curva de aprendizado suave: adota de biblioteca a framework completo, com renderização reativa otimizada por compilador.
## ⏰ Quando Utilizar
- Outra opção na faixa de melhor custo-benefício em [[frameworks_frontend_web|Frameworks de frontend web]]; opção essencial da camada.
- Escolha quando a linguagem e o ecossistema do projeto combinam com a ferramenta.
- Adoção incremental: começa como biblioteca em uma página e escala para framework completo com Vue Router e Pinia.
### Quando NÃO utilizar
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
- Quando o time já domina outro modelo de componentes do ecossistema React ou Angular.
