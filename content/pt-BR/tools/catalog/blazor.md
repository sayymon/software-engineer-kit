## 📝 Descrição
Framework de frontend web em C# e .NET com componentes reutilizáveis que rodam no cliente (WebAssembly) ou no servidor.
## ⏰ Quando Utilizar
- Outra opção na faixa de qualidade máxima em [[frameworks_frontend_web|Frameworks de frontend web]]; filtre pela linguagem do projeto no kit.
- Escolha quando o requisito é o máximo de recursos e o time já trabalha com C# e .NET.
- Um só modelo de componentes roda no navegador via WebAssembly, no servidor dentro do ASP.NET Core e embutido em apps nativos.
### Quando NÃO utilizar
- Quando o time não trabalha com C#/.NET: filtre [[frameworks_frontend_web|Frameworks de frontend web]] pela linguagem do projeto no kit.
- Quando suporte dedicado, SLA ou recursos corporativos forem requisito.
