## 📝 Descrição
Ferramenta de teste de carga com cenários escritos em Python: usuários virtuais leves definidos em código atacam o sistema alvo, com modo distribuído em múltiplas máquinas e interface web para acompanhar as execuções em tempo real.
## ⏰ Quando Utilizar
- Cenários de carga em Python normal, com as bibliotecas do ecossistema reutilizáveis dentro do teste.
- Distribuir a carga por múltiplos workers quando um único host não sustenta o volume.
- Também é opção na faixa melhor custo-benefício em [[testes_qa|Testes e QA]].
### Quando NÃO utilizar
- Quando o time prefere cenários em JavaScript: [[k6|Grafana k6]].
- Quando precisa de interface gráfica para montar planos: [[apache_jmeter|Apache JMeter]].
