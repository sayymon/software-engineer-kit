## 📝 Descrição
Biblioteca Rust de SQL assíncrono com verificação das consultas em compile-time.
## ⏰ Quando Utilizar
- Outra opção em [[orm_acesso_dados|ORM e acesso a dados]]; filtre pela linguagem do projeto no kit.
- SQL assíncrono com verificação em compile-time: escolha quando o serviço Rust quer SQL direto, sem ORM completo, com as macros verificando as consultas contra o banco em compile-time.
### Quando NÃO utilizar
- Quando o orçamento precisa ser zero ou o requisito é o máximo de recursos corporativos.
