# Mapa de Fundamentos de Engenharia
## 📋 Informações
- **Tipo:** Tecnológico
- **Área:** Engenharia de Software
- **Relevância Atual:** Sim
## 📖 Descrição
Hub dos fundamentos de engenharia do kit: padrões de projeto e de arquitetura, estruturas de dados e algoritmos. Os padrões vivem em [[hub_patterns|Mapa de Padrões de Engenharia]]. Cada estrutura de dados é uma nota `tipo: EstruturaDeDados` (modelo Template-Estrutura-de-Dados) e cada algoritmo é uma nota `tipo: Algoritmo` (modelo Template-Algoritmo), com nome e categoria, entrada e saída, complexidade, pré-condições, limitações, casos de uso, metadados de implementação e testes, e pseudocódigo. O contrato de campos está em `docs/content-contract.md`.
