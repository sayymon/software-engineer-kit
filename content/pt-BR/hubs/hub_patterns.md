# Mapa de Padrões de Engenharia
## 📋 Informações
- **Tipo:** Tecnológico
- **Área:** Engenharia de Software
- **Relevância Atual:** Sim
## 📖 Descrição
Hub dos padrões de projeto e de arquitetura do kit: arquiteturas distribuídas, os 23 padrões GoF e padrões de IA. Cada padrão é uma nota `tipo: Padrao` (modelo Template-Padrao) com problema, quando usar e evitar, trade-offs, fontes oficiais, casos de uso que o demandam e ferramentas que o implementam. O contrato de campos está em `docs/content-contract.md`. As ferramentas ficam em [[hub_tools|Mapa de Ferramentas de Engenharia]] e [[hub_ai_tools|Mapa de Ferramentas de IA]].
