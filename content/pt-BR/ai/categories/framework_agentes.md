# Framework de agentes
## 📝 Descrição
Bibliotecas para construir agentes que planejam, chamam ferramentas e colaboram entre si.
## 🧰 Como aparece nas ferramentas
- SDK em Python ou TypeScript com abstrações de agente, ferramenta e memória
- Suporte a multiagente, estado e execução em produção
