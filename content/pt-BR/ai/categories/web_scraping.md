# Ferramentas de web scraping
## 📝 Descrição
Ferramentas que coletam e estruturam conteúdo da web para uso por modelos e pipelines.
## 🧰 Como aparece nas ferramentas
- Conversão de páginas em markdown ou JSON
- Rastreamento de sites e extração com esquema

- **Melhor custo-benefício:** [[firecrawl|Firecrawl]], Apify, Jina Reader
- **Qualidade máxima:** Bright Data, Zyte API, Browserbase
