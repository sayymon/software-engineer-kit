# Napkin

## 📋 Informações Básicas
- **Tipos:** Serviço, Plataforma (texto para visual)
- **Empresa/Fabricante:** [[napkin_ai|Napkin AI]]
- **Website:** https://www.napkin.ai
- **App:** https://app.napkin.ai/
- **Categorias:** Geração de imagem, Visualização com IA
- **Modelo de contratação:** free, subscription (Plus), per-seat (Pro/Team)
- **Preço (USD):** Free $0 (500 créditos/semana); Plus a partir de $9/usuário/mês (anual); Pro $22/usuário/mês
- **Data de verificação:** 2026-11-20
- **Fonte do preço:** https://www.napkin.ai/pricing/

## 📝 Descrição
Ferramenta que transforma texto em visuais editáveis: infográficos, diagramas, fluxogramas e gráficos. Cola-se o texto, aciona-se o "Napkinify" e escolhe-se o visual. Útil para explicar conceitos e comparações de forma rápida.

Exemplo: gerar um infográfico comparando Java e Kotlin.

## 🎯 Para Que Serve
Converter texto em visuais claros para apresentações, documentação e conteúdo didático, sem precisar de ferramenta de design.

### Casos de Uso
1. Infográficos de comparação (ex.: Java vs Kotlin)
2. Diagramas e fluxogramas a partir de texto
3. Visuais para apresentações e posts
4. Material didático e explicações rápidas

## ⏰ Quando Utilizar
- Quando precisa transformar texto em visual rápido e editável
- Quando quer ilustrar conceitos sem abrir ferramenta de design
- Quando produz conteúdo didático ou de marketing

### Quando NÃO utilizar
- Quando precisa de design pixel-perfect com controle total
- Quando o visual exige identidade de marca rígida no plano free (carrega marca Napkin)
- Quando precisa de geração de imagem fotorrealista (prefira ferramentas de geração de imagem)

## 🖥️ Compatibilidade e Plataformas
- **Plataformas:** web
- **Integra com:** exporta PNG/PDF (todos os planos) e PPT/SVG (planos pagos)
- **Requisitos:** conta Napkin; navegador

## 🔒 Restrições e Especificações
- **Context window / limites:** créditos por texto (cerca de 1 crédito por palavra selecionada).
- **Residência de dados / privacidade:** processamento na nuvem do Napkin.
- **Offline:** não.
- **ToS / licença:** uso sob ToS do Napkin; visuais free com marca.
- **Outras restrições:** exports PPT/SVG só em plano pago; créditos não reembolsáveis após uso.

## 🔧 Como Utilizar
1. Acesse https://app.napkin.ai/
2. Cole ou escreva o texto base.
3. Acione "Napkinify" e escolha o estilo de visual.
4. Edite e exporte (PNG/PDF no free; PPT/SVG no pago).
